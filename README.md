# Курсовая: Ray Tracing на CUDA (вариант 3)

Проект реализует упрощенный рейтрейсер на C++/CUDA в hexagonal архитектуре.

Ограничения уровня "на 3":
- без рекурсии;
- без текстур пола;
- без отражений и прозрачности;
- один источник света;
- простая геометрия без отдельных источников света на ребрах.

Вариант 3:
- тетраэдр;
- гексаэдр (куб);
- икосаэдр.

## Сборка

```bash
make
```

## Запуск

По умолчанию используется GPU:

```bash
./kp_raytracer
```

CPU-режим:

```bash
./kp_raytracer --cpu
```

GPU-режим явно:

```bash
./kp_raytracer --gpu
```

Печать дефолтной конфигурации:

```bash
./kp_raytracer --default
```

Программа читает конфиг из `stdin` в формате задания.
Если конфиг не передан, используются значения по умолчанию.

## Выход

Кадры пишутся как бинарный `PPM (P6)`.
Путь к файлу формируется по шаблону с `%d`, например `out/frame_%d.ppm`.

Во время рендера в `stdout` печатается:

```text
{frame}\t{milliseconds}\t{rays}
```

## Структура (hexagonal)

- `domain` — геометрия, сцена, платоновы тела;
- `application` — конфиг, камера, orchestration;
- `ports` — интерфейсы рендера и записи файла;
- `adapters/cpu` — CPU-рендер;
- `adapters/gpu` — CUDA-рендер;
- `adapters/file` — запись изображения;
- `adapters/cli` — точка входа.
